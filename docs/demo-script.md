# Demo Script

Before sending the demo externally:

1. Create a Vercel `Sharable Link` for the current production deployment.
2. Run `npm run demo:links -- 'PASTE_THE_VERCEL_SHARABLE_LINK_HERE'`.
3. Use the generated deep links below instead of manually editing URLs.
4. For the customer-facing walkthrough and talk track, use `docs/customer-demo-checklist.md`.

1. Start on `tradegraph/index.html` and explain the suite thesis: one evidence graph for `Company -> Opportunity -> Route`.
2. Open `tradegraph/use-cases/supplier-verification.html` and explain why a procurement lead buys VerifySME.
3. Open the workspace chip and sign in with the demo workspace.
4. Walk through `tradegraph/app/overview.html`: source health, suite metrics, and the cross-product command center.
5. Open `tradegraph/app/verifysme/queue.html`, apply a preset, and open a supplier dossier.
6. Show the official Udyam and MCA assisted flows inside VerifySME and explain the provenance drawer.
7. Open `tradegraph/app/tenderradar/pipeline.html`, switch company profiles, and inspect a tender with gaps and fit reasons.
8. Open `tradegraph/app/exportpulse/route-pipeline.html`, open a route, and explain readiness blockers and route actions.
9. Close on `tradegraph/pricing.html` or `tradegraph/docs.html` and explain the moat: historical public data, decision traceability, and cross-product drill-through.
