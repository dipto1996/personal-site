# User Flows

## Core public flow

1. User lands on portfolio site
2. User opens Dashboards section
3. User sees TenderRadar value framing and chooses a company profile
4. User scans matched tenders and fit metrics
5. User opens a tender detail
6. User shortlists a tender
7. User moves to product CTA / contact

## Secondary flow

1. User scrolls to Products & Solutions
2. User understands VerifySME -> TenderRadar -> ExportPulse system
3. User decides which wedge matches their use case
