# Acceptance Criteria

- User can navigate to `dashboards.html` and see TenderRadar render.
- User can navigate to `solutions.html` and see both VerifySME and ExportPulse render.
- User can switch between preset supplier / tender / export profiles and see the visible list change meaningfully.
- User can filter by search term and readiness / fit state.
- User can open a supplier, tender, or export route and see reasons, gaps, and actionable detail.
- User can shortlist items and the shortlist survives refresh via localStorage.
- The Solutions page clearly explains why the three products belong together.
