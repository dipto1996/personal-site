# TenderRadar

India-first procurement intelligence product wedge for the personal site.

## V1 scope

- Public-facing product surface embedded into the main portfolio site
- Interactive tender-fit dashboard powered by demo seed data
- Buyer-fit scoring and shortlist flow in the browser
- Product positioning for the broader VerifySME -> TenderRadar -> ExportPulse portfolio

## External blockers

- Live ingestion from procurement portals
- User auth and workspace persistence
- Email / webhook alert delivery

Those are intentionally abstracted behind docs and environment placeholders so the public V1 can launch without pretending those integrations are already provisioned.
